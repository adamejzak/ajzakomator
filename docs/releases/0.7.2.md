# unimux 0.7.2

- Settings now have generous space around the navigation and content, including the top, with a quieter card surface and no outer border.
- Each setting uses its own row: label and description on the left, control on the right. This applies to terminal options, notifications, AI usage and profile fields.
- Dropdowns use a compact Cursor-style menu: right-aligned placement, single-line option labels, a neutral checkmark, and no double focus outline or filled selected row.
- The Git panel places the commit composer at the top, uses a compact icon toolbar, and shows expandable changes with history and a slim graph below. Existing repository trust rules and push confirmations stay in place.
