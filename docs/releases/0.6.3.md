# ajzakomator 0.6.3

- Drag workspace cards to reorder grids, open files and Settings together. A blue insertion marker shows where the card will land; the strip scrolls when dragging near its edges.
- Card order is remembered separately for each project, including across reloads. Grid order also updates in the sidebar. Newly opened cards are appended and closing cards keeps the remaining order.
- Existing grid rename, tab close, file editing and unsaved-draft protection continue to work.

Validated with type checks, 611 unit tests, a production build and real Electron workspace checks covering mixed-card dragging, persistence, settings, file editing and draft recovery.
