# ajzakomator 0.6.6

- Automatic updates on macOS, without an Apple Developer certificate. The app downloads the release for your Mac (Apple Silicon or Intel) from GitHub, verifies its checksum, unpacks it, checks the bundle and replaces itself with a small script that rolls back on any problem. As on Windows, "Automatic" asks "Install now / Later" at start and "Manual" uses the status bar button; nothing installs without your click. If the app cannot replace itself (not in a writable Applications folder, running from the disk image) it falls back to the download link. This is experimental: it could not be tested on a real Mac before release, and the first update to a version that contains it is still a manual download.
- Missing Claude Code or Codex are detected. Instead of a grid where every cell prints "command not found" you get one compact card per cell with "Install", "Show instructions", "Change profile", "Check again" and "Start anyway". The detector also finds tools that are installed but not on the app's PATH (macOS apps started from the Dock, Windows after an installer changed PATH) and never blocks a cell when it cannot be sure, for example for shell aliases or profile-defined PATH entries. Profiles whose tool is missing are marked "(niezainstalowany)" in the new grid dialog and menus.
- Guided install of Claude Code and Codex. Choose a method (official installer, WinGet, Homebrew or npm, whichever can work on your machine), see the exact command, and confirm. It runs in a visible terminal, with clear messages for network, permission, proxy and PATH problems and a cancel button. When it finishes the cells start by themselves and you can sign in right away. Real official installers were not run during testing.
- macOS: the AI account limits panel now offers "Log in to Claude" for the main Claude login, and the first login is detected correctly (a cached Keychain failure used to hide it for 30 minutes).

Validated with type checks, unit tests, a production build, real Electron runs of detection, the missing-CLI cards, fake installers (success, failure, Ctrl+C, cancel, reopen) with PowerShell and cmd, and the macOS downloader against local redirecting servers. macOS-specific behaviour (codesign check, App Management permission, relaunch) was not tested on a real Mac.
