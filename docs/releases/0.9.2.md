# unimux 0.9.2

0.9.1 was tagged but never published (a flaky test on one build machine); everything planned for it ships here.

- **SSH view.** The SSH tile now opens a view in the main area instead of a narrow list: hosts as tiles by group with their connection state, your keys and local shells, and a details pane to edit a host or key, connect it or open it in a new grid. Select several hosts or a whole group to open them as one SSH grid, and add SSH cells to any grid from the Add menu or a cell's menu.
- **AI accounts.** Every Claude account now has one card, identified by its Anthropic account and organization, and the main account is simply the one signed in to Claude Code:
  - Switching accounts with another tool (for example cswap) or `claude /login` is noticed within about 20 seconds while the limits panel is on and the window is visible: no duplicate cards, no account silently dropped, and the app never renews a copy of a sign-in that another tool may hold, which caused false "sign-in expired" cards.
  - Make main account saves the outgoing sign-in first and writes the new one while holding Claude Code's lock files.
  - Sign in again refuses to turn a saved card into a different account; on the main card it signs Claude Code in again, makes the signed-in account main and saves the previous main sign-in on its card first.
  - Access denied (HTTP 403, for example a paused subscription) is no longer shown as an expired sign-in; limits are read at most every 3 minutes per account with the app's own client name, and rate limits are waited out with a margin.
  - The app never renews a copy of a sign-in that cswap also holds (including cards created by 0.9.0). Make main account still works for such a card while its copy is fresh, moving only the files; otherwise switch to it with cswap or sign in to it again.
  - After an interrupted swap that the app could not recover on its own, clearing the warning marks the outgoing account as switched out, and its card keeps its own saved sign-in until the Claude Code sign-in changes or you sign in to the card again.
- **Status.** A Claude cell no longer reports "waiting for you" while a dynamic workflow is still running; it alerts once when Claude's next turn ends.
- **SSH fixes.** The "connecting" line always comes before the server greeting, and a key that cannot sign falls back to the saved password or the password prompt instead of ending the session. SSH sessions are still not restored after a restart of the app.
