# unimux 0.9.2

- **Renew a saved copy in unimux.** A saved Claude card that cswap also lists (including cards created by 0.9.0) now offers "Renew this copy in unimux" in its menu and under the cswap note. After a confirmation the app treats the copy as its own sign-in and renews it itself, so you no longer have to sign in again to an account you already signed in to in unimux. Sign in again stays available for sign-ins that have really expired.
- **SSH mode.** While the SSH view is in front, the left side panel shows its sections: Hosts, Keys, Known hosts and SFTP (coming soon). Hosts gets a row of group tiles that filter the list, Keys its own key tiles with the key details next to them, Known hosts the trusted host keys with Remove; clear empty states show the first step. Projects, Files, Git or a grid tab bring the normal side panel back.
- **Show and replace a private key.** The key details in the SSH view get a Private key section: Show private key (after a confirmation, with Copy and Hide key; it disappears after 2 minutes or when you leave the key), Save private key to file and Replace private key, which takes a pasted key, keeps the label and the hosts that use it, and tells you when the public key changed so you can update `authorized_keys` on your servers.
- **A calmer SSH view.** The details pane appears only when you pick a host or key and closes with its X, Esc or a second click, so the list uses the full width otherwise. The Groups row lists All and your groups (no tile for hosts without a group) and is hidden when you have no groups; local shells are no longer listed in Hosts (they stay in the Add menu); host tiles are a bit more compact.
- **Bulk send.** "Send to all" is now called Bulk send in the SSH view, the palette and the grid tab menu. Typing in the host search now also narrows the multi-selection, so "Open as grid (n)" counts only the hosts you see.
