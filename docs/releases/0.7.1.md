# unimux 0.7.1

- A consistent dark dropdown replaces system menus throughout settings, grid creation, notifications and Git. Supports keyboard navigation, type-to-search and visible selection.
- New grids receive a color automatically. Workspace tabs are shorter, top toolbar buttons are more compact, and active sidebar panels and projects use a clearer background.
- Sidebar icons use a restrained 20 px size, thinner strokes and smaller active tiles, with simple folder and source-control marks.
- Terminal focus is outlined on all four sides; header labels, status indicators and terminal actions are aligned consistently.
- The file explorer uses colorful file-type icons and a compact project header with new file, new folder and refresh actions.
- Files align closer to the left edge without empty folder-chevron space. The Files panel no longer shows Add project at the bottom.
- Context menus use compact rows, subtle separators and plain shortcut labels. Folder menus omit Open in editor.
- File breadcrumbs are brighter, use chevrons, and flow directly into the editor. Save, wrap and close controls are simplified.
- Uses the supplied Unimux logo throughout the app, installers and update splash, with the new banner in both README languages. Brand source artwork lives in `resources/branding`.
- The current-version status is a compact green indicator next to the version, with details on hover.

Po polsku: odświeżony, bardziej kompaktowy interfejs — ciemne listy wyboru, kolorowe ikony plików, czytelne okruszki ścieżki, niższe zakładki, automatyczne kolory gridów i poprawione obramowanie oraz nagłówki terminali. Nowa ikona i banner marki są używane w aplikacji, instalatorach i README.
