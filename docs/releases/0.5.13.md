# ajzakomator 0.5.13

- Much faster installs and updates on Windows. The app is now packed into a single archive (48 files instead of about 3,500), the installer is 106 MB instead of 122 MB, a fresh install takes about 10 seconds instead of about 50 and every later update about 20 seconds instead of about 75. The first update from 0.5.12 still removes the old files once and takes about 30 seconds. Start-up of the installed app is also a little faster.
- There are now exactly two update modes in Settings. "Automatic" checks for an update when the app starts and asks "Install now" or "Later" (X and Escape mean "Later"). "Manual" does nothing at start and installs only when you click the update button in the status bar. Updates are never installed silently or on close any more. If you had the old automatic install turned on, you now get the question at start instead. In Automatic mode the download starts in the background while the question is shown, and the repeated check right after start was removed.
- No more "waiting for you" notifications or sounds while an agent still has background tasks or subagents running. A Claude cell stays "working" until the work is really finished.
- Claude cells now follow conversation changes made inside the terminal (/resume, /clear, forks): after a restart the cell comes back to the conversation you were actually in, and its title is correct.
- Conversation history is indexed with a cache and without blocking the app, and cells that run in a git worktree now show their conversation titles too.
- The sidebar shows the same status badges with counts for grids as for projects (for example 1 working, 2 working and 1 waiting), without the separate dot and the layout number. The grid tabs at the top use the same badges.
- Fixed the update window locking the new app archive, which could stop an update from finishing. Hook requests from a stopped agent process can no longer overwrite the state of a restarted cell.

Validated with type checks, unit tests, a production build, real Electron runs of the hook handling, background tasks, history cache and sidebar, and real end-to-end updates with local installers (0.5.12 to the new layout, new to new in both update modes, "Later", Escape, no update, and broken update feeds).
