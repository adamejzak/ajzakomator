# ajzakomator 0.5.6

- Fixed the title bar buttons (search, AI, history, snippets, panels, settings) disappearing off screen when many grid or file tabs were open. The window layout now always stays within the window.
- Grid cells now resize independently: each row has its own vertical dividers, so you can widen a single cell in the top row without moving the bottom row. Horizontal dividers move a whole row of cells. Double-click a divider to restore its equal split; each grid keeps its own proportions.
- Added a "What's new" window in the status bar. It lists the release notes of every version from GitHub, marks the installed and newer versions, and keeps a saved copy for offline use.
- Added an update setting in Settings: install updates automatically when the app is closed (default), or only when you click the update button in the status bar. Updates still download in the background.
- Restores the macOS packages and update manifest that were missing from releases 0.5.4 and 0.5.5.

Validated with type checks, unit tests, a production build and real Electron runs that resized grids row by row, opened the changelog from GitHub and changed the update setting.
