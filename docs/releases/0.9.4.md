# unimux 0.9.4

- **The MCP token stays out of the agent's tools.** Claude cells now get their per-cell MCP token only in their private MCP config file (readable only by you, deleted when the agent stops), not in the environment, so scripts, dev servers and packages the agent runs can no longer pick it up. Codex cells still read it from a variable, which Codex hides from the commands it runs by default.
- **Faster start.** The main window is created right away instead of after the hook server, the MCP server, the SSH setup and the saved-accounts recovery; those now run in parallel behind it. The MCP SDK, the updater and the SSH key library load the first time they are needed. In a test with two projects and a grid of four shells the window is created about 0.45 s sooner, ready about 0.4 s sooner and the first terminal output arrives about 0.4 s sooner.
- **Same safety at start.** Account actions (Set as main, sign in, remove, refresh limits) wait until an interrupted account switch has been repaired, and cells start their agents only once the hook and MCP servers are listening; the window shows the cells meanwhile.
- **Startup timings in startup.log.** The data folder keeps the timings of the last 20 starts (from launch to the first terminal output), to help find what makes a start slow.
- **Every cell of a big grid draws on the GPU.** Grids with more than 12 terminals used to draw the extra cells through the much slower DOM renderer. Now all cells of the largest 5x4 grid get a WebGL renderer: with 20 busy shells the window's main thread spends about 15-25% less time per second, layout work drops from about 35 ms per second to zero and the slowest frame drops from about 20 ms to 12 ms. If the GPU ever allows fewer contexts, the focused cell and the cells with fresh output get them first, a cell keeps a new context for a few seconds (no flickering back and forth), and a terminal whose GPU context was lost comes back on WebGL after a short pause.
- **Error cards follow the language.** If the status bar or a dialog fails to draw, its "try again" card now switches language together with the rest of the app.
- **Lighter start.** The window loads only the texts of your language: its main code is about 340 KB smaller, and another language loads when you pick it, without a moment of untranslated texts.
- **Sandboxed window.** The app window now runs in Chromium's sandbox, so a problem in the page can reach less of your system.
- **Smaller app package.** Type declarations, sources and docs of the bundled libraries and a second copy of the MCP SDK are no longer shipped (the Windows app archive shrinks from 16 MB to 12 MB).
- **Fewer wake-ups when idle.** The status check runs only while there are terminals, and session titles are refreshed only for projects with cells bound to a conversation.
