# ajzakomator 0.6.0

- Settings now open as a workspace tab beside grids and files. A compact sidebar separates app settings, terminal options, notifications, updates, AI accounts and agent profiles. The active section uses a simple background highlight, and stays selected when switching between tabs.
- Markdown files now open in a styled preview with headings, tables, quotes, code blocks and task lists. Switch to source editing and back without losing unsaved changes. Heading links scroll within the document, and relative file links open files from the project. Embedded HTML is sanitized; images currently appear as descriptive text or links.
- Project rows show only the project name. The Add project button sits below the project list instead of above it, with a lighter appearance. In the file view it remains available at the bottom of the sidebar.
- Cleaner terminal headers: compact role and MCP controls sit beside the terminal actions, conversation names use the available space, and the working status aligns with the other labels. Full names and MCP state remain available in tooltips.
- Aligned the empty snippet message with the search field and refreshed the styling of the changelog refresh button.
- The app version appears only in the bottom-left status bar, without repeating the app name. Removed the version beside the top-left logo.
- Closing the Settings tab with Ctrl+Shift+W restores the previous workspace view without closing a background grid. Focusing a terminal returns to its grid from Settings or a file.

Validated with type checks, 530 unit tests, a production build and real Electron workspace checks covering navigation, layout, file editing, draft recovery and safe Markdown rendering.
