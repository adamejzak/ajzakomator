# unimux 0.8.3

- Windows portable builds are no longer published. Use the installer (`unimux-Setup-<version>.exe`): it keeps itself up to date. Your data lives in the app's data folder, so switching from a portable copy to the installer keeps your projects and settings.
- The release description now shows the real version number in the download table, and the "Po polsku" paragraph is gone from release notes.
