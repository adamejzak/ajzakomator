# unimux 0.8.0

- Git panel: compact Cursor-style layout, a commit check mark in the Changes header (with "add everything and commit"), collapsible and resizable history, one-line commits with branch/remote icons, spinning refresh, and Pull requests / Issues from GitHub. Without a repository the panel offers `git init` and installing Git.
- Files tree shows Git marks (U, M, A, D) at the right of each row and a dot on folders with changes.
- Diffs open as editor tabs and wrap long lines. Files over 256 KB open read-only (windowed), CSV/TSV and Parquet show as tables, images as images, `.env` files are highlighted, and Ctrl + wheel / Ctrl +/-/0 zooms the file views.
- Settings are grouped with descriptions, darker selects and a new colour picker. Notifications are one table with a master switch; agent profiles have typical start options (`--yolo`, `--dangerously-skip-permissions`, models) explained before they are switched on.
- Drag files and folders from the system file manager into a cell to insert their path; agents now receive forward slashes. A conversation renamed with `/rename` updates the cell title. The version lives in one place (bottom left); the application icon is set explicitly on every platform.
- MCP: `create_grid` builds a whole team in one call (`count`, `after`).
