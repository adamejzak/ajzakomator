# unimux 0.5.5

- Added a status bar along the bottom of the window with the running version and live update status: checking, up to date, downloading with progress, ready to install, and errors. The update action (restart to install, or download on portable and macOS builds) is a button there.
- Grid cells can be resized: drag the dividers between cells to widen or narrow columns and rows, double-click a divider to restore the equal split, or focus it and use the arrow keys. Each grid keeps its own proportions, including merged and uneven layouts.
- "Add project" moved to the top of the sidebar, above the Projects and Files tabs.
- Search (Ctrl+K) moved to the top bar next to the other buttons. The sidebar footer is gone.
- The project path moved from the top right of the title bar to the active project in the sidebar.

Validated with type checks, unit tests, a production build and a real Electron run that dragged dividers, reloaded the saved proportions and checked the new layout.
