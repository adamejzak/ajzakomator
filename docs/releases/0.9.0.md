# unimux 0.9.0

- **SSH connections.** The SSH tile in the left rail is now a small SSH client built into the grid (no `ssh` program needed):
  - Save hosts with a label, address, port, user, group and tags; search and fold groups. Click a host to connect in the active grid, or open a group (or several selected hosts) as a grid with one session per host. The grid dialog and presets can hold SSH cells too.
  - Keys: generate Ed25519, ECDSA or RSA keys, or add one from a file (also by drag and drop) or as pasted text, with an optional passphrase. Copy the public key for `authorized_keys`.
  - Sign in with a key, a saved password, a password prompt or one-time codes. The first connection asks you to trust the server's fingerprint; a changed host key shows a red warning and needs a confirmation.
  - "Send to all" types one command into the checked SSH sessions of the current grid. Each host can have a startup command.
  - Keys and saved passwords are encrypted with Windows DPAPI or the macOS Keychain and never reach the window, the logs or agents (MCP). Trusted host keys are listed in Settings > SSH.
  - SSH sessions are not restored after a restart of the app and never reconnect on their own; the cell offers "Connect". On macOS the Keychain may ask again for access to "unimux Safe Storage" after an update.
- **Git panel.** Fetch, pull and push now sit in the branch bar with the number of commits to pull and to push, next to a single refresh button; the history header only holds history controls. In a narrow panel the branch name stays readable.
- **App identity and data folder.** On Windows the app ID is now `com.unimux.app` (macOS keeps its bundle ID for now so the updater accepts this version), and the data folder moves from `%APPDATA%\ajzakomator` to `%APPDATA%\unimux` (on macOS `~/Library/Application Support/unimux`) on the first start after the update, with a link left at the old location. Installed apps keep updating in place, and the taskbar shortcuts get the new identity, which fixes a leftover Electron icon on the taskbar.
