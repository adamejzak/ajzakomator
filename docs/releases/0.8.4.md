# unimux 0.8.4

- The renderer and main process bundles are now minified: the main interface chunk shrinks by about 40% and the file editor chunk by about 43%.
- The package no longer ships README artwork or build-only headers, so `app.asar` is about 27% smaller and updates download less.
- Adds `npm run perf`, a startup and idle profile of the built app (boot time, first paint, heap, DOM size, idle CPU, process memory).
