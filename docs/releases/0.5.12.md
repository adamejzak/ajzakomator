# ajzakomator 0.5.12

- Update modes: Settings now has three choices - Manual (default), Ask on start and Automatic on start. "Ask on start" shows a short window with "Install now" and "Later" when a new version is available; X and Escape mean "Later". "Automatic on start" installs without asking. Manual only uses the update button in the status bar. The old "install automatically" setting is migrated: on becomes Automatic, off becomes Manual. Going back to an older app version resets Automatic users to Manual.
- Faster start of an update from a closed app: the runtime used by the update window is now prepared in parallel with the download instead of at the very end. The startup check window is shown for at least a moment so it does not flash, and an update prompt that cannot be shown never blocks the app from starting.
- New option "Alerts while the window is active" (off by default). When on, the notification and the waiting sound also fire for the cell you are looking at.
- Drag cells to swap places: grab the header of a cell and drop it on another one. Splitter sizes are kept, terminals are not restarted and the moved cell keeps focus. Escape cancels the drag. The keyboard shortcut is Ctrl+Alt+Shift+arrows and there are four "Cell: move" commands in the command palette.
- Smoother terminals with many agents: cheaper replay history in the terminal host, adaptive batching of output, flow control with back-pressure for floods of output, and no DOM rebuilds in terminals that are not visible. With nine busy cells the terminal host CPU dropped from about 18% to 5% and hidden cells use about 4 times less renderer CPU. A cell can no longer freeze when a process exits or a renderer is gone.

Validated with type checks, unit tests, a production build, and real Electron runs of cell dragging, the update prompt against a local update feed, and load measurements with fake agents.
