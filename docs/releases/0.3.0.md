ajzakomator 0.3.0 adds app languages and macOS builds.

- Choose English, Polish, German, Spanish, French or Portuguese on first launch. Change the language immediately in Settings; the preference is saved across restarts. Existing installations keep Polish.
- Native macOS packages for Apple Silicon (ARM64) and Intel (x64), with zsh/bash terminals, Cmd shortcuts, terminal copy/paste and shell login PATH support.
- GitHub Actions tests and builds Windows x64 and both Mac architectures, including a real terminal test inside each packaged application.
- Resize side panels, reorder projects and snippets, browse project files, and customize project icons.
- Updated English and Polish READMEs with installation instructions for both platforms.

| Platform | Download |
| --- | --- |
| Windows installer | `ajzakomator-Setup-0.3.0.exe` |
| Windows portable | `ajzakomator-Portable-0.3.0.exe` |
| macOS Apple Silicon | `ajzakomator-0.3.0-mac-arm64.dmg` |
| macOS Intel | `ajzakomator-0.3.0-mac-x64.dmg` |

ZIP packages are also available for macOS. Drag the app from the DMG into Applications. Mac builds are signed ad hoc and are not notarized; if macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway. Mac and portable Windows updates are downloaded manually; the installed Windows app updates automatically.
