# unimux 0.9.3

- **AI team inboxes no longer fill up for good.** Tasks and messages are now limited per project (500 each) instead of 500 for the whole app forever: finished tasks and read messages older than 7 days are removed automatically, the oldest finished ones make room when a project is full, and removing a project removes its items. The Tasks and Messages tabs can remove finished items (one or all).
- **No duplicate teams.** A `create_grid` that a client gave up on rolls back its worktrees, and repeating the same team call within 5 minutes returns the first answer instead of starting a second team. Codex cells give unimux tools 180 s instead of 60 s.
- **Faster tool calls for Claude cells.** The status hooks around every tool call run in the background, and all Claude hooks bypass an HTTP proxy (like the Codex hook), so status keeps working behind a corporate proxy.
- **Smoother with many agents.** Session titles read only the new end of a growing Claude transcript and list Codex sessions newest first without blocking the app; identical git reads on window focus share one run; find in files stops a search you already replaced; terminal output of several busy cells reaches the window as one message.
- **Fewer pauses in the main process.** Opening a file in the editor, checking project folders (also on offline network drives), the Windows PATH lookup before a cell starts and the saved accounts list no longer block the app.
- **MCP reliability.** A failed MCP server start is retried (and can be retried from the AI team panel), internal errors are logged, an oversized result stays valid JSON, "MCP connected" means the agent's client really loaded the tools, and agent statuses update at once instead of every 2 s. Native Codex delivery on Windows starts `codex.exe` directly.
- **Cleaner data folder.** Startup prompts are deleted once the agent started, and hook and MCP files of removed cells are deleted.
