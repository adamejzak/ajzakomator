# unimux 0.9.3

- **Smoother typing in the file editor.** A keystroke no longer re-renders the whole window and every terminal cell, and unsaved drafts are written to storage at most every 0.7 s instead of on every key (they are still written right away before a reload, when the window is hidden and when the app quits, so a draft survives a reload).
- **Resizing panels and grid cells without the stutter.** While you drag the edge of a side panel or a divider in the grid, the cells keep their size and every terminal is fitted once when you let go, instead of reflowing its history and making the agent redraw at every pause of the mouse. Cells that the drag does not touch are not redrawn at all.
- **Fewer redraws in large grids.** A change elsewhere (snippets, settings, another project, a cell renamed) no longer redraws every cell of the grid, and main's confirmation of your own change no longer redraws what you already see. The tab strip and the project list redraw only when a status badge count really changes.
- **Lighter "working" dot.** The pulse of the working status dot now runs on the GPU compositor instead of repainting every frame, and it stops when the system asks for reduced motion.
- **Long Git histories stay fast.** The history list renders only the rows in view (up to 3000 loaded commits), typing in its search field no longer redraws the list, and typing a commit message no longer rebuilds the list of changed files. The Git panel code loads when the panel is first opened.
- **Smaller things.** Ctrl+wheel zoom in a terminal fits once per frame, the command palette filters only when the query changes, and a hidden Settings page no longer redraws on every change.
