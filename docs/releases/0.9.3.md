# unimux 0.9.3

- **A fast file tree for big projects.** The Files panel now draws only the rows you can see and loads all open folders in a few batched requests, so "Expand all folders" on a project with about 26,000 files and folders takes about 0.3 s instead of almost 8 s, and opening, closing and scrolling stay smooth. Keyboard navigation, selection, rename, drag and drop, the context menus, git markers and "Show in Files panel" work as before; Page Up and Page Down now move through the tree too.
- **Parent folders stay pinned while you scroll.** Like in VS Code, the folders that contain the first visible row stay at the top of the tree (up to five levels, the closest ones), so you always see where you are. Click a pinned folder to jump to it, or its arrow to collapse it.
- **No more staircase in deep folders.** The indent per level is smaller and stops growing after a few levels, thin guide lines mark each level, long names end with an ellipsis (the full path is in the tooltip) and the tree no longer scrolls sideways.
