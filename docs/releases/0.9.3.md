# unimux 0.9.3

- **AI team inboxes no longer fill up for good.** Tasks and messages are now limited per project (500 each) instead of 500 for the whole app forever: finished tasks and read messages older than 7 days are removed automatically, the oldest finished ones make room when a project is full, and removing a project removes its items. The Tasks and Messages tabs can remove finished items (one or all).
- **No duplicate teams.** A `create_grid` that a client gave up on rolls back its worktrees, and a retry of a team call the client gave up on gets the first answer instead of starting a second team. Codex cells give unimux tools 180 s instead of 60 s.
- **Faster tool calls for Claude cells.** The status hooks around every tool call run in the background, and all Claude hooks bypass an HTTP proxy (like the Codex hook), so status keeps working behind a corporate proxy.
- **Smoother with many agents.** Session titles read only the new end of a growing Claude transcript and list Codex sessions newest first without blocking the app; identical git reads on window focus share one run; find in files stops a search you already replaced; terminal output of several busy cells reaches the window as one message.
- **Fewer pauses in the main process.** Checking project folders (also on offline network drives), the Windows PATH lookup before a cell starts and the saved accounts list no longer block the app.
- **MCP reliability.** A failed MCP server start is retried (and can be retried from the AI team panel), internal errors are logged, an oversized result stays valid JSON, "MCP connected" means the agent's client really loaded the tools, and agent statuses update at once instead of every 2 s. Native Codex delivery on Windows starts `codex.exe` directly.
- **Cleaner data folder.** Startup prompts are deleted once the agent started, and hook and MCP files of removed cells are deleted.
- **Unsaved SSH edits are kept.** Picking another host or key, switching between Hosts, Keys and Known hosts or closing the SSH tab while the details pane has unsaved changes now asks first, like Esc and X. Cancel keeps the item and your edits; a form without changes switches as before. Going to the grid or Settings keeps the draft in the background without asking, as before.
- **Copied private key is cleared on quit too.** The one-minute clearing of a copied private key now also happens when you quit the app within that minute, and reloading the window no longer stops it (only if the clipboard still holds the key). A copy that fails shows an error instead of nothing.
- **Account actions only from the app window.** Signing in, cancelling a sign-in, removing an account, making an account the main one, renewing a saved copy, clearing an interrupted swap, dismissing an account notice and refreshing usage are accepted only from the unimux window itself.
- **A fast file tree for big projects.** The Files panel now draws only the rows you can see and loads all open folders in a few batched requests, so "Expand all folders" on a project with about 26,000 files and folders takes about 0.3 s instead of almost 8 s, and opening, closing and scrolling stay smooth. Keyboard navigation, selection, rename, drag and drop, the context menus, git markers and "Show in Files panel" work as before; Page Up and Page Down now move through the tree too.
- **Parent folders stay pinned while you scroll.** Like in VS Code, the folders that contain the first visible row stay at the top of the tree (up to five levels, the closest ones), so you always see where you are. Click a pinned folder to jump to it, or its arrow to collapse it.
- **No more staircase in deep folders.** The indent per level is smaller and stops growing after a few levels, thin guide lines mark each level, long names end with an ellipsis (the full path is in the tooltip) and the tree no longer scrolls sideways.
- **Cells come back after a terminal process crash.** When the background process that runs the terminals restarts, your Claude, Codex and shell cells start again by themselves instead of staying blank. An SSH stream error no longer takes every other terminal down with it.
- **A crashed or frozen window recovers.** If the app window crashes (for example out of memory in a large grid), it reloads by itself and picks up the running terminals with their output. After several crashes in a minute, or when the window stops responding, the app asks whether to reload, wait or quit.
- **One broken part no longer blanks the window.** A cell, the side panel, the status bar or a dialog that fails to draw shows a small card with Try again, and the rest of the app keeps working. Grids with a damaged saved layout are repaired when the app starts.
- **Repeated terminal crashes.** After the terminal process crashed several times in a row, the app offers Restart terminals or Quit (without freezing the app behind the message), and cells say why they cannot start.
- **Safer saving.** The app state is saved atomically, flushed to disk and retried when antivirus, indexing or OneDrive holds the file for a moment; a failed save is kept and tried again instead of being lost. A damaged state.json is kept next to it as a backup, and the backup copy is refreshed every hour. Changes from the last moments are also saved when Windows signs out or shuts down.
- **Clear start failures.** If unimux cannot start, it shows the reason and exits instead of staying invisible in the background (where later launches did nothing). It also starts when the local hook server is blocked.
- **A cell that cannot start says why.** A failed start (for example a locked or full disk) shows its error in the cell instead of leaving it blank.
- **Clean quit.** Terminals that do not end in time when you quit are stopped together with the programs they started.
- **macOS: Cmd+Q and the Edit shortcuts.** The app has a minimal menu again, so Cmd+Q quits and copy, paste, cut, select all and undo work in text fields.
- **Crash log.** Errors of the app (also from the window and the terminal process) are written to `crash.log` in the app data folder, so problems can be traced.
- **Smoother typing in the file editor.** A keystroke no longer re-renders the whole window and every terminal cell, and unsaved drafts are written to storage at most every 0.7 s instead of on every key (they are still written right away before a reload, when the window is hidden and when the app quits, so a draft survives a reload).
- **Resizing panels and grid cells without the stutter.** While you drag the edge of a side panel or a divider in the grid, the cells keep their size and every terminal is fitted once when you let go, instead of reflowing its history and making the agent redraw at every pause of the mouse. Cells that the drag does not touch are not redrawn at all.
- **Fewer redraws in large grids.** A change elsewhere (snippets, settings, another project, a cell renamed) no longer redraws every cell of the grid, and main's confirmation of your own change no longer redraws what you already see. The tab strip and the project list redraw only when a status badge count really changes.
- **Lighter "working" dot.** The pulse of the working status dot now runs on the GPU compositor instead of repainting every frame, and it stops when the system asks for reduced motion.
- **Long Git histories stay fast.** The history list renders only the rows in view (up to 3000 loaded commits), typing in its search field no longer redraws the list, and typing a commit message no longer rebuilds the list of changed files. The Git panel code loads when the panel is first opened.
- **Smaller things.** Ctrl+wheel zoom in a terminal fits once per frame, the command palette filters only when the query changes, and a hidden Settings page no longer redraws on every change.
- **Alerts on time while the window is minimized or covered.** The app no longer lets Chromium slow down its timers in the background, so status changes and "needs you" alerts keep their usual pace and busy terminals keep their full output speed while you work in another window. While the window is minimized or hidden, terminals stop drawing and give back their GPU contexts, and they redraw when you bring the window back.
- **No spell checker.** Text fields no longer underline paths, branch names and commands, and the app no longer downloads spelling dictionaries.
- **Smaller macOS download.** The macOS app no longer carries the terminal module's Windows files (about 60 MB) and ships only the six app languages of Chromium, like the Windows build.
- **Security updates.** Electron 44.9 (Chromium security fixes), DOMPurify 3.4.17 and marked 18.1.1.
