# unimux 0.5.8

- Added an "AI accounts" section docked at the bottom of the sidebar. It shows how much of the 5 hour and 7 day limits of your Claude and Codex accounts is used, with the reset time and a countdown. Reading the limits never spends any usage and never calls a model.
- The section collapses to compact chips and shows both limits in the narrow sidebar rail too. Providers that are not signed in are hidden, and an expired or revoked login is shown as a muted card with a "Sign in again" button instead of stale numbers.
- Added a "+" button to add accounts: another Claude account (shown next to the main one with its own limits) or the Codex login. Sign-in runs the provider's own login command in a controlled window with an embedded terminal, so no token is ever typed or copied. Accounts added in the app can be removed from the card menu. Adding extra Claude accounts is not available on macOS yet.
- Added settings to show or hide the section and to choose the refresh interval (1, 5 or 15 minutes).
- Redesigned the snippets panel: a single "new snippet" button, flat rows instead of heavy cards and a lighter search field.
- New grid cells get their own accent color automatically, and grid dividers are easier to grab.
- Find and replace across project files, one expand/collapse toggle in the Files tab, turning arrows while refreshing or checking for updates, and a calm message when updates cannot be checked.

Validated with type checks, unit tests, a production build and real Electron runs with fake accounts, a fake limits server and fake login commands that covered adding, duplicate, cancel and removing accounts, expired logins and token renewal.
