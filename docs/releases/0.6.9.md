# unimux 0.6.9

- The left panel is rebuilt as a vertical rail of tiles instead of the two text tabs: Projects, Files, Git and SSH. Clicking the open tile folds the panel, the collapsed state is the rail alone, and panels are registered in one place so new ones are easy to add. The SSH tile is a greyed-out placeholder for a future connection manager.
- Drag a file or a folder from the Files panel onto a chat cell and its path goes into the conversation without being sent: `@path` for Claude, the plain path for Codex, a correctly quoted path for a shell (several selected items are inserted together). It also works in a plain terminal cell where you started `claude` or `codex` by hand: the app recognises the agent and uses its format, and the cell menu has "Wstawianie ścieżek" (Auto, Claude, Codex, Shell) to override a wrong guess. The tree menu has "Dodaj do rozmowy".
- New "Skróty klawiszowe" section in Settings: every shortcut can be rebound by pressing the new combination, conflicts with another action are flagged with a warning and a swap option, terminal- and system-critical keys are reserved, and each shortcut can be reset or disabled. Shortcuts are shown in the command palette and tooltips.
- New Git panel: branch and ahead/behind, changed files (stage, unstage, commit), history with a lane graph and commit details, read-only diffs, fetch, pull (fast-forward only) and push with a confirmation that shows the target URL. A repository whose local configuration can start programs (filters, hooks, fsmonitor and similar) stays read-only until you explicitly trust it, and the panel never runs such programs on its own.

Validated with type checks, unit tests (including real temporary repositories with local remotes and a hostile repository), a production build from a clean `npm ci`, and a real packaged Windows installer in a lab: the rail, the Git panel and its trust banner, rebinding shortcuts, path drops, background loading and an update run. macOS, deleting files to the real recycle bin and real OS-level drag and drop were not tested.
