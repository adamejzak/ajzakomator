# unimux 0.7.0

- **The app is now Unimux.** The app has a new U-shaped terminal mark, updated icons, window titles and interface text across all six languages. Windows installers, portable builds and both Mac packages now use the `unimux` name.
- The repository has moved to **daven-team/unimux**. Download links, update feeds, release workflows, documentation and README screenshots now point to the new project.
- Existing projects, terminal layouts, conversations, snippets and saved accounts stay available. Unimux retains the original local data directory and application identity for compatibility with previous installations.
- MCP integrations now use the `unimux` server name. Restart or resume existing agents from the app to apply the new launch configuration.
- Includes the latest 0.6.9 workspace features: the left rail, Git panel, configurable keyboard shortcuts and dragging file paths into agent conversations. Git repository detection also handles Windows short paths, links, letter case and slash differences correctly.

Po polsku: **Aplikacja zmienia nazwę na Unimux**. Nowe logo, ikona, nazwy paczek, dokumentacja i screeny są spójne z nową marką. Projekty, rozmowy, ustawienia i zapisane konta pozostają dostępne. Aby zastosować nową konfigurację MCP, uruchom ponownie lub wznów agentów z aplikacji.
