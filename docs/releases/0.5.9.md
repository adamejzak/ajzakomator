# ajzakomator 0.5.9

- With automatic updates on, the updater now runs first when you start the app. It shows a short "Checking for updates" window; if a new version exists it downloads and installs it with a progress bar before the app opens. With no update, no network, a timeout or any error, the app starts normally, and a failed update is not retried for 6 hours. Manual updates (now the default for new installs) still use the update button in the status bar.
- Fixed starting the app while an update installer was still running, which could show a vanishing update window and an error. The app now waits for the installer instead of cleaning up under it.
- Fixed the "waiting for you" notification firing again for restored cells every time the app starts, and after waking the computer from sleep.
- Agent status is more accurate: a Claude agent that is running subagents or tools stays "working" instead of flipping to "waiting for you", and clicking a window or typing no longer makes the status disappear. A cell that was interrupted with Esc now returns to "waiting" after a few seconds.
- Added an optional sound when a cell starts waiting for you (Settings: off, system sound or your own audio file, with volume and a test button). It follows the same rules as notifications and works for Codex cells too.
- The collapsed AI account limits panel is calmer and shows both the 5 hour and 7 day limits with their reset countdowns; the arrow points up when collapsed and down when expanded.
- The README download badge now counts only real package downloads instead of update metadata files.

Validated with type checks, unit tests, a production build and real Electron runs of the startup update check against a local update feed, agent statuses and notifications with fake agents, and the sound option.
