# ajzakomator 0.6.7

- Codex status is now precise. Codex cells are started with a per-process `notify` hook that reports the end of every turn to ajzakomator (your Codex config file is not touched). Each cell is bound to its own Codex conversation, even when several Codex cells run in the same folder, so after restarting the app every cell resumes its own conversation (`codex resume <id>`) instead of starting a new one. The binding is saved after the first finished turn. A notify from a sub-agent in the middle of a turn is ignored; the turn end is confirmed only after a short quiet moment.
- No more repeated Codex notifications after the window was minimized and restored: one alert per turn per cell, and the window visibility changes, wake from sleep and focus no longer re-run the idle heuristics.
- A usage limit is no longer shown as "waiting for you". Claude turns that end with an API error and the Codex "You've hit your usage limit" message show a red "limit reached" (or "error") label and raise the error alert with its own sound. The Codex message is recognised only as a real error line, not in quoted text, code or search results, and the label clears if the agent keeps working.
- New per-cell "Mute alerts" switch in the cell menu.
- Account limits: when the limits of a saved Claude account cannot be read, the card now says why (rate limit with the retry time, server error, network, refresh problem, swap in progress) instead of a generic error, keeps the last numbers greyed out with their age, and has "Copy diagnostics" in its menu (no tokens, no e-mail). A refresh that races with a running Claude session no longer marks the account as expired, and a saved account that holds the same login as the main one is read through the main login and never refreshed.
- Codex notify is a legacy Codex setting; if a future Codex removes it, cells fall back to the previous heuristic status. A `notify` program you configured yourself is replaced for the cells started by the app.

Validated with type checks, unit tests, a production build, and real Electron runs with a fake home and fake Codex and Claude programs (per-cell hooks, binding of two cells in one folder, restart and resume, sub-agent notifications, minimize and restore, limit messages, mute, usage failure reasons). Real Codex and real Claude hook sequences were not run; their formats come from the documentation and source code.
