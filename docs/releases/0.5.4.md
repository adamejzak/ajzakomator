# ajzakomator 0.5.4

- Installing an update now shows a dedicated ajzakomator window with the logo, the version change, a progress bar and the current step (preparing, closing, installing, starting). It stays on screen until the new version has opened, so there is no silent wait after accepting the installer prompt.
- The window runs from a private copy of the Electron runtime prepared in the background once the update is downloaded, so the installer can replace the installed app while progress remains visible. It also appears when an update installs on quit, and it offers a manual start if an update takes unusually long.
- The window texts are available in all app languages.

The window is shown when updating from 0.5.4 to a later version; updating from older versions to 0.5.4 still installs silently.

Validated with type checks, unit tests, a production build and an end-to-end run of the update window against a real Electron runtime.
