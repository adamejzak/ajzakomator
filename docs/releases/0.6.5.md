# unimux 0.6.5

- Sounds and notifications are rebuilt around three events: an agent finished, an agent needs you (permission prompt or question) and an agent hit an error such as a rate limit. Each event has its own system notification switch and its own sound: one of eight built-in presets (default "ding-dong", chime, soft bell, marimba, pluck, retro, alert, low warning), the system beep, your own audio file or off. There are test buttons, a volume slider, quiet hours and the existing "also in the active window" option. System notifications are always silent, so there is no double sound. Your previous notification and sound settings are migrated.
- Claude cell status is tracked more reliably. A turn that ends with an API error (for example "You've hit your weekly limit") no longer leaves the cell on "working"; it shows "waiting" with an error alert. Late tool hooks after a finished turn no longer flip the cell back to working, a turn that continues after a custom Stop hook alerts when it really ends, long background shell tasks no longer silence "finished" alerts, stale background tasks after a restart no longer keep a cell "working" for minutes, and clicking a cell never changes its status. MCP automation now reports the same status as the interface.
- New command palette entry "Skopiuj dziennik statusów" copies a short log of status changes (no message text) so unexpected statuses can be diagnosed.
- A main Claude account whose access token expired while Claude Code was idle is no longer shown as logged out. The card shows the last known limits with a calm note that Claude Code renews the token on its next use, and the limits refresh as soon as the login file changes.

Validated with type checks, unit tests, a production build and real Electron runs with a fake home: hook sequences for statuses and alerts, per-event sounds and notifications, migration of old settings, and the dormant account state. Real Claude Code hook sequences for background tasks were checked against the documentation only.
