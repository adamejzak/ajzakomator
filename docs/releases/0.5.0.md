# ajzakomator 0.5.0

## Workspace

- Grid and file tabs now sit below the navbar with a rectangular shape. Rename and color grid tabs from their context menu.
- Grid tabs use a grid icon, file tabs use a document icon, and the editor toolbar has aligned controls.
- Open project text files in editable workspace tabs. Save with Ctrl+S / Cmd+S; modified files offer save, discard or cancel on close. Drafts survive a reload, and saving detects external disk changes.
- The CodeMirror editor adds line numbers, syntax highlighting for common code/config formats, folding, bracket matching, search, indentation and undo/redo.
- Removed project drag grips while keeping drag-to-reorder. Removed the file explorer footer.
- Sidebar resizing uses a neutral highlight and reliably clears after release, capture loss or window blur.
- The app name shows the version, animates on click and offers Check for updates on right-click.
- Update status now shows checking, download percentage, transferred size, speed, restart and actionable errors.
- Terminal links use a styled confirmation dialog. MCP role menus match the dark UI.

## MCP teams

- Apply a role and restart/resume the agent in one action, with clear configured, connected and restart-required states.
- Add agents to an existing grid or create a background team; choose names, colors, profiles and model overrides.
- Rename and color grid tabs through MCP. Close another grid through MCP, stopping its agents and preserving it in History.
- Task dependencies enforce readiness before claiming or delivering work.
- `read_inbox` combines tasks and unread messages and can acknowledge returned messages in one call, reducing tool chatter.
- Compact task cards open detailed views; the task form appears when creating a task.

## Documentation and validation

- Refreshed English and Polish READMEs with current English screenshots, editor usage and practical team workflows.
- Expanded MCP guides and added reproducible screenshots and Electron workspace checks.
- 157 unit tests pass, along with type checks, the build and real Electron workspace/MCP smoke tests. Updater tests explicitly cover Windows installation and macOS manual downloads on every CI host. Release CI also verifies packaged terminal runtimes on Windows x64 and both macOS architectures.

Text editing supports preview-sized text files (up to 256 KiB); binary and larger files can be opened externally. MCP inbox persistence does not guarantee a model will wake automatically: native delivery depends on CLI/session support. Windows installer builds support automatic updates; portable Windows and macOS builds use manual downloads.
