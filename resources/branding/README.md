# Unimux artwork

`logo.png` and `banner.png` are the original supplied brand assets. Both README languages display the banner at its original aspect ratio.

Run `npm run icons` to export `resources/icon.png` (1024 px), `resources/icon-64.png` (UI) and `resources/icon.ico` (seven Windows sizes). The complete square artwork and transparency are preserved without cropping. The app, Windows/macOS packages and update splash all use that same icon.
