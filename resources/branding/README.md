# Unimux artwork

`logo.png` and `banner.png` are the original supplied brand assets. Both README languages display the banner at its original aspect ratio.

Run `npm run icons` to export `resources/icon.png` from the logo. The export trims the surrounding black margin, keeps the mark centered with padding, and scales to 1024×1024. The app, Windows/macOS packages and update splash all use that same icon.
